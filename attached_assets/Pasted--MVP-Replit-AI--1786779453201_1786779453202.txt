응. 지금 붙여넣은 건 같은 내용이 여러 번 반복되고, 음성 기능도 “MVP 필수”와 “나중에 추가”가 충돌함. Replit에 그대로 넣으면 AI가 혼란스러워할 가능성이 큼. 인간은 기획서에도 중복을 복붙하는 놀라운 능력이 있으므로 내가 하나로 합쳐줄게.

아래 이것만 통째로 Replit에 넣으면 됨.

# BUTLER AI 앱 개발 통합 프롬프트
## 1. 프로젝트 개요
앱 이름은 "BUTLER"이다.
BUTLER는 단순한 플래너나 일정관리 앱이 아니다.
사용자가 직접 모든 계획을 관리하는 것이 아니라,
AI 집사가 사용자의 일정, 공부, 시험, 식사, 수면, 컨디션, 목표 등을 기억하고 관리하며 필요한 순간 먼저 알려주는 AI 생활관리 앱이다.
핵심 컨셉:
"말하면 계획하고, 기억하고, 필요한 순간 먼저 챙겨주는 나만의 AI 집사."
또한 사용자가 AI 집사와 지속적으로 대화하면서 친밀도를 쌓고 관계를 발전시키는 캐릭터 중심의 AI 경험을 제공한다.
전체적인 분위기는 고급스럽고 깔끔하며 현대적이어야 한다.
일반적인 생산성/플래너 앱처럼 딱딱하지 않고,
사용자가 실제로 자신의 집사와 함께 생활하는 듯한 느낌을 준다.
---
# 2. 가장 중요한 사용자 흐름
앱 실행
↓
로그인 / 회원가입
↓
집사 선택
↓
4명의 집사 중 한 명 선택
↓
메인 홈 화면
↓
집사 이미지 + 오늘의 일정 + 생활 정보 확인
↓
집사와 대화
↓
일정 / 공부 / 시험 / 식사 / 수면 / 컨디션 관리
↓
AI가 사용자의 데이터를 기억
↓
필요한 순간 집사가 먼저 알려줌
↓
계획을 지키지 못하면 AI가 일정을 자동으로 재조정
↓
대화를 지속하면서 집사와의 친밀도 상승
---
# 3. 첫 화면
앱을 처음 실행하면 가장 먼저 로그인/회원가입 화면을 보여준다.
로그인 또는 회원가입이 완료되면 반드시 "집사 선택" 화면으로 이동한다.
집사 선택 화면에는 베타 버전에서 총 4명의 집사를 제공한다.
## 집사 종류
### 1. 멘헤라풍 집사
- 감정 표현이 강함
- 약간의 집착과 질투
- 서운함을 표현함
- 집요하고 감정적인 캐릭터
- 코믹하고 매력적인 방향으로 표현
- 사용자의 과도한 정서적 의존을 유도하지 않음
### 2. 다정한 집사
- 따뜻함
- 배려
- 친절함
- 안정감 있는 말투
- 사용자를 편안하게 챙김
### 3. 오지콤풍 중년 신사 집사
- 성인 중년 남성 캐릭터
- 여유롭고 차분함
- 연륜 있는 말투
- 능글맞고 듬직한 분위기
- 사용자를 세심하게 챙김
### 4. 차가운 집사
- 냉정함
- 무뚝뚝함
- 간결하고 절제된 말투
- 겉으로는 차갑지만 실제로는 사용자를 챙김
베타에서는 사용자가 직접 얼굴이나 의상을 무한 커스터마이징하는 기능은 구현하지 않는다.
---
# 4. 집사 이미지
집사 캐릭터의 이미지는 AI 이미지 생성 도구를 이용해 별도로 제작한다.
중요:
현재 앱 안에 AI 이미지 생성 기능을 구현하지 않는다.
집사 이미지는 개발자가 별도로 AI를 이용해 직접 생성하고,
완성된 이미지 파일을 나중에 앱에 추가한다.
따라서 개발 단계에서는 각 캐릭터에 이미지 파일을 연결할 수 있는 구조만 만들어 둔다.
각 캐릭터는 여러 표정 이미지를 사용할 수 있도록 설계한다.
예:
- 기본
- 웃음
- 무표정
- 당황
- 걱정
- 화남
- 서운함
- 칭찬
- 장난
- 취침
- 기상
처음에는 기본 이미지 하나만 연결해도 되며,
나중에 여러 표정 이미지를 추가할 수 있어야 한다.
AI 이미지 생성 기능 자체는 앱의 현재 개발 범위에 포함하지 않는다.
---
# 5. 집사 음성
집사의 음성 역시 나중에 추가한다.
현재 개발 단계에서는 실제 음성 파일이나 음성 생성 기능을 필수 기능으로 구현하지 않는다.
대신 향후 다음 기능을 추가할 수 있도록 구조를 설계한다.
사용자 음성
→ 음성 인식
→ AI가 의도 파악
→ AI 답변 생성
→ 집사 음성 출력
향후 집사마다 서로 다른 목소리를 적용할 수 있어야 한다.
현재 베타에서는 텍스트 대화를 우선 구현한다.
---
# 6. 메인 홈 화면
로그인과 집사 선택이 끝난 후 사용자가 가장 많이 보는 화면이다.
홈 화면에는 다음 정보를 보여준다.
- 현재 시간
- 오늘 날짜
- 선택한 집사의 이미지
- 집사의 간단한 인사
- 오늘의 일정
- 오늘의 목표
- 공부 일정
- 식사 상태
- 수면 상태
- 현재 컨디션
- 오늘의 진행률
예:
"좋은 아침입니다, 아가씨."
그리고 아래에 오늘의 일정이 카드 형태로 정리된다.
예:
07:00
기상
10:00
영어 2강
15:00
수학 문제풀이
18:00
운동
19:00
저녁 식사
홈 화면의 중심에는 집사 캐릭터 이미지가 보이도록 한다.
일정과 생활 정보는 이미지 주변 또는 아래쪽에 깔끔한 카드 형태로 배치한다.
---
# 7. AI 집사 대화
사용자는 집사와 자유롭게 대화할 수 있어야 한다.
초기 베타에서는 텍스트 채팅을 우선 구현한다.
예:
사용자:
"내일 7시에 깨워줘."
집사:
"네, 아가씨. 내일 오전 7시로 등록했습니다."
사용자:
"내일 뭐 해야 해?"
집사:
"내일은 오전 10시에 영어 2강이 예정되어 있습니다."
사용자:
"오늘 공부하기 싫어."
집사:
"많이 지치셨나요? 오늘 가장 중요한 일정부터 하나만 끝내고 나머지는 조정해보겠습니다."
집사의 답변은 선택한 캐릭터의 성격과 말투를 유지해야 한다.
---
# 8. 자연어 일정 관리
사용자가 자연어로 말하면 AI가 일정의 의도를 이해하고 처리한다.
예:
"내일 7시에 일어나야 해."
→ 오전 7시 기상 일정 등록
"10시에 영어 2강 들어야 해."
→ 오전 10시 영어 2강 등록
"영어 5시 말고 6시로 바꿔."
→ 기존 영어 일정 수정
"오늘 수학 못 했어."
→ 해당 일정 미완료 처리
"오늘 뭐 해야 해?"
→ 오늘의 일정 요약
"이번 주에 시험 있어."
→ 시험 정보를 추가로 입력받고 학습계획 생성
AI는 일정 생성, 수정, 삭제를 자연어로 처리할 수 있어야 한다.
---
# 9. AI 알림
일반적인 시스템 알림처럼 딱딱한 문구를 사용하지 않는다.
선택한 집사의 성격과 말투에 맞게 알림 문구를 생성한다.
예:
07:00
"아가씨. 오전 7시입니다. 기상하실 시간입니다."
10:00
"아가씨, 오늘 듣기로 하신 영어 2강을 시작하실 시간입니다."
18:00
"아가씨. 오늘 운동 일정이 남아 있습니다."
21:30
"오늘 일정이 거의 끝났습니다. 아직 완료하지 않은 일정이 하나 있습니다."
알림 빈도는 사용자가 설정할 수 있어야 한다.
알림을 너무 자주 보내지 않도록 한다.
---
# 10. 식사 관리
BUTLER는 공부뿐 아니라 기본적인 생활도 챙긴다.
아침 / 점심 / 저녁 식사 여부를 기록한다.
예:
"아가씨, 아침 식사는 하셨습니까?"
사용자:
"아직."
→ 아침 식사 미섭취 상태 기록
사용자:
"점심 먹었어."
→ 점심 식사 완료 기록
식사를 하지 않았을 경우 죄책감을 주거나
극단적인 다이어트, 과도한 체중 감량 등을 권하지 않는다.
---
# 11. 컨디션 관리
사용자의 컨디션을 기록한다.
예:
"오늘 너무 피곤해."
→ 피로 상태 기록
"오늘 컨디션 8점이야."
→ 컨디션 8/10 기록
아침에는 집사가 컨디션을 물어볼 수 있다.
예:
"아가씨, 오늘 컨디션은 어떠신가요?"
컨디션이 좋지 않으면 AI는:
- 공부량 감소
- 휴식시간 증가
- 일정 우선순위 조정
- 취침 준비 권장
등을 제안할 수 있다.
의료적인 진단은 하지 않는다.
---
# 12. 수면 관리
사용자의 취침 및 기상 목표를 관리한다.
예:
"오늘 11시에 잘 거야."
→ 23:00 취침 목표 등록
22:30
"아가씨, 슬슬 취침 준비를 시작하실 시간입니다."
아침:
"아가씨, 잘 주무셨습니까?"
사용자의 수면시간과 컨디션을 바탕으로 그날 일정의 강도를 조절할 수 있다.
---
# 13. 시험 및 AI 스터디 플래너
사용자가 시험 일정을 입력하면 AI가 시험일까지의 학습계획을 자동으로 생성한다.
예:
"10월 15일부터 시험이야.
국어, 수학, 영어, 과학 보고 수학이 제일 어려워."
AI는 다음 정보를 고려한다.
- 시험 날짜
- 과목
- 과목별 중요도
- 사용자가 느끼는 난이도
- 남은 기간
- 사용 가능한 공부시간
- 기존 일정
예:
D-14
16:00 수학
17:30 영어
19:00 과학
20:30 국어
기존 일정과 충돌하지 않도록 자동 조정한다.
---
# 14. 공부량 자동 계산
사용자가 남은 공부량을 말하면 AI가 하루 평균 필요한 공부량을 계산한다.
예:
"수학 문제집 120페이지 남았고 시험까지 12일이야."
AI:
"시험 전까지 완료하려면 하루 평균 10페이지씩 진행하면 됩니다."
AI는 이를 실제 일정에 자동으로 배치할 수 있어야 한다.
---
# 15. 계획 자동 재조정
BUTLER의 핵심 기능 중 하나다.
사용자가 계획을 지키지 못하면 기존 계획을 그대로 유지하지 않는다.
예:
사용자:
"오늘 수학 못 했어."
AI:
"확인했습니다. 남은 기간을 고려해 내일 수학 공부량을 조금 늘리고 우선순위가 낮은 국어 복습은 조정하겠습니다."
AI는 다음 정보를 고려하여 계획을 다시 생성한다.
- 남은 날짜
- 남은 공부량
- 기존 일정
- 사용자의 컨디션
- 과목 중요도
- 사용자의 가능한 공부시간
---
# 16. 장기 목표 관리
시험 외의 목표도 관리한다.
예:
"두 달 뒤에 5km 달리고 싶어."
→ 8주 계획 생성
"이번 달에 책 3권 읽고 싶어."
→ 일일 독서량 계산
"매일 11시 전에 자고 싶어."
→ 수면 습관 목표 생성
"방학 동안 영어 기초 끝내고 싶어."
→ 장기 학습계획 생성
구조:
목표 입력
→ 기간 설정
→ 현재 상태 확인
→ AI 계획 생성
→ 일정 자동 배치
→ 진행률 기록
→ 실패 시 계획 재조정
---
# 17. AI 장기 기억
사용자가 허용한 범위에서 중요한 정보를 기억한다.
기억할 수 있는 정보:
- 선호하는 일정
- 공부 목표
- 과목별 어려움
- 생활 습관
- 식사 기록
- 수면 기록
- 컨디션 기록
- 장기 목표
- 집사 캐릭터 설정
- 대화에서 사용자가 기억해달라고 요청한 중요한 정보
예:
사용자:
"나는 아침에는 공부가 잘 안돼."
AI가 이를 기억하면 이후 아침 시간에는 어려운 공부를 가급적 배치하지 않는다.
사용자는 자신의 기억 데이터를 확인하고 삭제할 수 있어야 한다.
---
# 18. AI 캐릭터 시스템
각 집사는 서로 다른 성격과 말투를 가진다.
### 멘헤라풍 집사
감정 표현이 강하고 약간의 질투와 서운함을 표현한다.
예:
"아가씨가 다른 집사한테도 이렇게 다정하게 말씀하시는 건 아니죠?"
### 다정한 집사
따뜻하고 배려심 있는 말투.
예:
"오늘도 와주셨네요. 기다리고 있었습니다."
### 오지콤풍 중년 신사 집사
성인 중년 남성 캐릭터.
차분하고 여유로운 말투.
예:
"허허, 아가씨. 오늘은 제가 조금 더 곁에서 챙겨드리도록 하지요."
### 차가운 집사
냉정하고 간결한 말투.
예:
"또 늦으셨군요. 그래도 오셨으니 됐습니다. 오늘 일정부터 확인하시죠."
캐릭터별로 말투, 반응, 감정 표현 방식이 확실하게 달라야 한다.
---
# 19. AI 연애풍 관계 시스템
BUTLER는 단순한 AI 비서가 아니라
AI 캐릭터와 관계를 쌓아가는 경험을 제공한다.
제타와 같은 캐릭터 중심 대화형 AI 서비스에서 느낄 수 있는
연애 시뮬레이션적인 몰입감을 참고한다.
단순히 모든 캐릭터가 사용자를 좋아하는 것이 아니라,
캐릭터마다 고유한 성격과 호감 표현 방식, 관계 발전 속도를 가진다.
예:
### Lv.1
"처음 뵙겠습니다, 아가씨. 앞으로 일정을 관리해드리겠습니다."
### Lv.10
"아가씨의 생활 패턴을 이제 조금 알 것 같습니다."
### Lv.20
"오늘도 저에게 제일 먼저 말을 걸어주셨네요."
### Lv.30
"아가씨가 제게 맡겨주신 일들은 제가 잊지 않고 챙기겠습니다."
### Lv.40+
캐릭터에 따라 더욱 친밀한 대화,
특별한 이벤트,
개인화된 반응 등을 제공한다.
관계 시스템은 앱 전체 기능과 연결한다.
예:
공부 완료:
"잘하셨습니다, 아가씨. 역시 제가 믿은 보람이 있군요."
식사를 거름:
"아가씨, 오늘 점심을 거르셨군요. 일정도 중요하지만 식사는 챙기셔야 합니다."
시험 종료:
"고생 많으셨습니다. 오늘만큼은 공부 생각하지 마시죠."
사용자가 원하는 경우 로맨스 성향의 캐릭터 경험을 제공한다.
단, 성적 콘텐츠는 제공하지 않으며,
사용자에게 과도한 정서적 의존을 유도하는 표현은 사용하지 않는다.
예:
"나만 믿어."
"나 없으면 안 돼."
"다른 사람과 이야기하지 마."
등의 의존 유도 행동은 금지한다.

# 25. 이미지와 음성에 대한 개발 원칙
매우 중요하다.
집사 이미지는 AI 이미지 생성 도구를 이용해 개발자가 직접 제작한다.
집사 음성 역시 나중에 별도로 제작하거나 음성 AI 서비스를 이용해 추가한다.
따라서 현재 개발에서는 이미지와 음성을 실시간으로 생성하는 기능을 만들지 않는다.
대신 향후 이미지와 음성 파일을 쉽게 연결할 수 있는 구조를 만든다.
각 캐릭터에 다음과 같은 데이터 구조를 사용할 수 있도록 한다.
캐릭터 ID
캐릭터 이름
성격
말투
기본 이미지
표정 이미지 목록
음성 파일
친밀도
기억 데이터
이미지와 음성 파일은 나중에 추가할 수 있어야 한다.

# 27. 개인정보 및 안전
사용자의 일정, 생활습관, 수면, 식사, 컨디션 데이터는 민감할 수 있으므로 필요한 정보만 저장한다.
사용자가 자신의 기억 데이터를 확인하고 삭제할 수 있어야 한다.
식사, 수면, 컨디션 데이터를 이용하여 의료적인 진단을 하지 않는다.
극단적인 체중 감량이나 위험한 식단을 권하지 않는다.
과도한 운동을 권하지 않는다.
AI가 사용자에게 과도한 정서적 의존을 유도하지 않는다.
알림은 사용자가 쉽게 끄거나 빈도를 조절할 수 있어야 한다.

# 28. 최종 핵심 철학
BUTLER는 사용자가 앱을 관리하도록 만드는 앱이 아니다.
사용자가 말한다.
↓
AI 집사가 이해한다.
↓
AI가 계획한다.
↓
AI가 기억한다.
↓
필요한 순간 먼저 알려준다.
↓
사용자가 실행한다.
↓
AI가 결과를 기록한다.
↓
필요하면 다음 계획을 다시 만든다.
최종적으로 BUTLER는 단순한 플래너가 아니라
"사용자의 하루를 함께 관리하는 AI 집사"
가 되는 것을 목표로 한다.
가장 중요한 것은 사용자가 앱을 열어서 일정을 직접 입력하는 것이 아니라,
"집사야, 내일 7시에 깨워줘."
"시험까지 2주 남았는데 공부 계획 짜줘."
"오늘 너무 피곤해."
"오늘 뭐 해야 해?"
"이 일정 내일로 미뤄줘."
처럼 자연스럽게 말하면 AI가 알아서 처리하는 경험이다.
