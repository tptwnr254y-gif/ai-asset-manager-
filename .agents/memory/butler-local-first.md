description: API 키가 없는 환경에서도 BUTLER의 핵심 사용자 흐름을 유지하는 제품 결정
---

BUTLER의 첫 MVP는 외부 AI API가 없어도 로그인 데모 세션, 집사 선택, 일정, 생활 기록, 목표, 기억, 관계 화면이 실제로 작동해야 한다. AI 대화는 외부 전송 없이 준비된 한국어 응답으로 동작시키고, 실제 모델 호출은 별도 응답 경계에 나중에 연결한다.

**Why:** 사용자가 OpenAI API 키를 아직 보유하지 않았고, API 없이도 UI와 핵심 비AI 기능을 먼저 검증하기를 원했다.

**How to apply:** 향후 AI 연동을 추가할 때도 로컬 핵심 흐름을 깨지 말고, 키가 없거나 연결이 실패하면 같은 안전한 로컬 응답으로 돌아가도록 유지한다.
